## 📐 开发规范

- **能自动化就自动化**：重复操作写成脚本 / Action，不手动跑第二遍
- **先跑通再美化**：功能可用优先，最后统一清理与优化代码
- **不空跑、不重复**：每一步产出都要落地，避免无意义的重试
- **前端优先静态化**：能用静态站 + CDN 就不上后端，部署快、成本低
- **隐私优先**：个人项目默认自托管 / 本地优先
